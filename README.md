# Movies App

A movie, TV show and people browser built with React and the TMDB API. Search titles, open movie details, and save favorites.

**Live demo:** https://movies-app-nu-one.vercel.app

## Features

- Browse movies, TV shows and popular people
- Search with pagination
- Movie details page
- Favorites list
- Sign up and sign in with protected routes
- Arabic and English language support

## Tech stack

- React 18, React Router
- Redux Toolkit
- Axios
- Bootstrap 5
- TMDB API
- Deployed on Vercel

## Getting started

```bash
git clone https://github.com/ahmedketaa/MoviesApp.git
cd MoviesApp
npm install
npm start
```

Open http://localhost:3000.

## Scripts

| Command | Description |
| --- | --- |
| `npm start` | Start the development server |
| `npm run build` | Create a production build |
| `npm test` | Run tests |
